# ♻️ SizaClean

## Smart Waste Collection Reporting System

SizaClean is a web-based Smart Waste Collection Reporting System designed to improve communication between residents, waste collectors, and municipal authorities.

The system allows residents to report waste-related problems, authorities to manage and assign reports, and waste collectors to update the progress of assigned reports.

### Tagline

> Report. Track. Clean.

---

## 📌 Project Title

**Design and Development of a Web-based Smart Waste Collection Reporting System for Improving Waste Management in Urban Communities**

---

## 🎯 Project Objective

The main objective of SizaClean is to provide a centralized web-based platform for reporting and managing waste collection problems.

The system aims to:

- Allow residents to report waste-related problems online.
- Allow residents to track the progress of their reports.
- Allow municipal authorities to view and manage submitted reports.
- Allow authorities to assign reports to waste collectors.
- Allow waste collectors to view reports assigned to them.
- Allow waste collectors to update report statuses.
- Notify users when important changes occur.
- Improve communication between residents and waste management staff.
- Maintain a record of waste reports and their progress.

---

## 👥 System Users

SizaClean has three main user roles.

### 1. Resident

Residents can:

- Register and log in.
- Submit waste reports.
- Select a waste problem type.
- Provide a description of the problem.
- Provide the location.
- Upload an optional photograph.
- View their submitted reports.
- Track report status.
- Receive notifications.
- Mark notifications as read.
- Reset their password if necessary.

### 2. Municipal Authority

Municipal authorities can:

- Log in using an authority account.
- View all waste reports.
- Filter reports by status, problem type, and location.
- View report details.
- Assign reports to waste collectors.
- Monitor report progress.
- View dashboard summary information.
- Receive notifications when new reports are submitted.

### 3. Waste Collector

Waste collectors can:

- Log in using a collector account.
- View reports assigned to them.
- Start work on assigned reports.
- Change a report from **Assigned** to **In Progress**.
- Mark completed reports as **Resolved**.
- Receive notifications when reports are assigned to them.
